# रत्न कार्ड

इस फ़ोल्डर में अलग-अलग 2D PNG कार्ड हैं। हर तैयार कार्ड में ऊपर पूरा फ़ाइल-नाम और नीचे उसी रत्न की इमेज है। कार्ड 1920 × 1954 px हैं। नाम, रंग, आकार और प्रतीक मूल द्वंद्व 34-रत्न पैक के अनुसार रखे गए हैं।

**प्रगति: 20/34 कार्ड तैयार।** `21_shukra.png` से `34_shunya.png` तक के 14 कार्ड अभी बाकी हैं; अगली उपलब्ध image-generation quota window में जोड़े जाएँगे। सूची को अधूरे संग्रह के रूप में स्पष्ट रखा गया है—यह 34/34 पूरा होने का दावा नहीं है।
