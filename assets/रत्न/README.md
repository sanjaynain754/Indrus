# रत्न कार्ड

इस फ़ोल्डर में अलग-अलग चमकदार 2D PNG कार्ड हैं। हर कार्ड में ऊपर पूरा फ़ाइल-नाम और नीचे उसी रत्न की इमेज है। सभी कार्ड 1920 × 1954 px हैं। नाम, रंग, आकार और प्रतीक मूल द्वंद्व 34-रत्न पैक के अनुरूप रखे गए हैं।

**प्रगति: 30/34 कार्ड तैयार।** अंतिम चार कार्ड `31_satya.png` से `34_shunya.png` तक अगली उपलब्ध image-generation quota window में जोड़े जाएँगे; संग्रह अभी अधूरा है।

- सभी 34 रत्नों की शक्तियाँ, फायदे और चरित्र में उपयोग: [`../../रत्न-विवरण/README.md`](../../रत्न-विवरण/README.md)
- संयुक्त पूर्वावलोकन (30/34), इस फ़ोल्डर के बाहर: [`../रत्न-संग्रह.png`](../रत्न-संग्रह.png)
