# द्वंद्व ब्रह्मांड

यह सेक्शन ब्रह्मांड का बुनियादी L1 canon रखता है। कहानी में जिस ग्रह का इस्तेमाल हो, उसी का विस्तार करें; बाकी ग्रह-कार्डों को फिलहाल यथावत रखें। शिलाधार पृथ्वी-मणि का पैतृक ग्रह है और धरा अलग से पृथ्वी (मानव-ग्रह) है।

- [ब्रह्मांड पुस्तिका](BRAHMAND.md): ढाँचा, यात्रा/समय के नियम, ग्रह-प्रकार और सभी ग्रहों की सारणी।
- [5 आकाशगंगा कार्ड](galaxies/): पंचभूत, त्रिगुण, सप्त चक्र, नवग्रह और द्वंद्व।
- [36 ग्रह कार्ड](planets/): 34 मणि-गृह, धरा और सृष्टि-केंद्र; कार्डों में दिए खाली खाने आगे भरने के लिए हैं।
- [CSV डेटा](brahmand.csv)
- [JSON डेटा](brahmand.json)

विकार का असर ग्रह-कार्डों में सुझाव है, अनिवार्य canon नहीं; कहानी का कोई निश्चित साल तय नहीं है।
